# Wikipedia-Search-App

This is a small project where you can search Wikipedia directly from a simple webpage.  
You type any word or phrase, press search, and it shows you a list of related articles with short snippets. Clicking on any result opens the full Wikipedia page in a new tab.

Features
- Search Wikipedia instantly without leaving the page
- Clean and minimal interface
- Shows titles and short previews of articles
- Each result links to the full article on Wikipedia
- Handles errors like empty input or no matching results

Built With
- HTML for the page structure
- CSS for styling and layout
- JavaScript for handling the search and fetching data from the Wikipedia API

How to Run
1. Download or clone this repository
2. Open the file index.html in your browser
3. Type a search term and start exploring

Future Improvements
- Show images or thumbnails with each result
- Add pagination for more results
